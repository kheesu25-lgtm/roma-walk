SETTINGS / GOOGLE MAPS

Google Maps API 키

키는 이 브라우저(localStorage)에만 저장되며 서버로 전송되지 않아요. 저장하면 페이지가 새로고침됩니다.

Google Cloud 콘솔에서 Maps JavaScript API를 사용 설정하고, 도보 경로(Directions)를 쓰려면 해당 API도 켜 주세요. 키는 사용할 도메인(HTTP 리퍼러)으로 제한하는 것을 권장해요.
